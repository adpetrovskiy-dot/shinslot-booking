# ШинСлот

Рабочий прототип сайта записи для шиномонтажа на Vinext / Cloudflare Workers / D1.

## Уже работает

- Мобильная витрина с услугами, ценами и записью в четыре шага.
- Расчёт стоимости по диаметру, типу авто и RunFlat до выбора времени.
- Свободные слоты с учётом длительности, буфера и количества постов. Сервер повторно проверяет место при вставке записи.
- Подтверждение или заявка, персональная ссылка для отмены.
- Админка: недельный календарь, список и статусы записей, ручная запись, редактор прайса, расписания и бренда.
- Черновик, мобильный предпросмотр и публикация настроек.

## Запуск локально

```sh
npm ci
npm run db:generate
npm run build
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_ordinary_gertrude_yorkes.sql
npm run dev
```

Локальная админка: `/admin`. Для входа используйте локальную имитацию ChatGPT sign-in по ссылке на странице.

## Граница текущей версии

Сейчас развёрнут один демонстрационный шиномонтаж с ключом `demo`. Хостинг приватный для владельца. Перед продажей нескольким точкам нужны маршрутизация по доменам и изоляция владельцев, уведомления, загрузка изображений, юридические тексты обработки персональных данных и публичный режим доступа. Демонстрационные адрес и телефон необходимо заменить в админке.
